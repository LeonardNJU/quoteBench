QuoteBench

QuoteBench holds a model's Bash command fixed and replays it through one added parser, then lets the model see that boundary. The crossover separates transport damage from contract-conditioned compensation and shows when a matched score hides both.

What the crossover shows

Each task asks for one Bash command and is scored by exact final state, so any correct quoting strategy passes. Eight same-window configurations supply the controlled evidence.

Transport damage

The same command loses 55–73 points behind one added parser.

Replaying each raw reply through one added bash -c layer lowers exact-final-state success by 55.4–73.2 points in all eight configurations. A real ssh boundary reproduces the damage for seven of eight to the decimal.

Compensation

Seeing the boundary recovers 30–61 points for six configurations.

Replies generated under a disclosed-boundary contract recover 30.4–60.7 points on the nested path for six configurations and zero or slightly negative for the other two. Two further public draws keep every damage negative and change no compensation sign.

Matched scores

A matched score can hide the dependency.

The two effects cancel at one frontier configuration: GPT-5.6-sol’s matched gap of −3.6 hides −64.3 damage and +60.7 compensation. Elsewhere the matched score falls with the path, and the deployment configuration reorders models (Kendall τ 0.57 between raw and nested orderings).

Attribution

A known hazard, attributed to its cause.

Quoting failures are documented; QuoteBench holds the reply fixed and changes one parser, so each loss is attributed to transport or to generation. A fixed-commit survey of six agent systems finds boundaries applied downstream of the stated contract, such as Codex executing a native command field as shell -c. Correct escaping or a temporary script removes the effect, and evaluations should report contract, execution path, operating point, and validator.

Run your own model

The public package generates, executes, and scores with the Python standard library and Docker. Point it at any OpenAI-compatible endpoint, run the two contracts, and the crossover command prints RR, RN, NR, NN, damage, and compensation for your model. The guide has the details and the cost per run.

export QUOTEBENCH_API_KEY=...
python3 -m quotebench run --model MODEL_ID \
  --base-url https://api.example.com/v1 \
  --contract raw --out raw.jsonl --executor docker
python3 -m quotebench run --model MODEL_ID \
  --base-url https://api.example.com/v1 \
  --contract nested-shell-v2 --out disclosed.jsonl --executor docker
python3 -m quotebench crossover --raw raw.jsonl --disclosed disclosed.jsonl
